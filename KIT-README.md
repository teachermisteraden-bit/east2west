# East to West Development Society — Claude Code website kit

Everything Claude Code needs to build a noble, immersive, bilingual website for **East to West Development Society** (جمعية الشرق إلى الغرب للتنمية).

## How to use
1. Create an empty project folder and unzip this kit into it.
2. **Optional but recommended:** run the Claude Design prompt (`assets/reference/east-to-west-claude-design-master-prompt.md`) first, then save its exports in a `brand/` folder here: logo SVGs, favicon set, tokens, motion logo spec, key screens, Open Graph images and prospectus PDFs. Without `brand/`, Claude Code builds with provisional tokens and swaps them in later.
3. Open the folder in Claude Code.
4. Open `00-MASTER-PROMPT.md`, copy everything below the line, and paste it into Claude Code.
5. Review and approve at the end of each of the six phases.

## What's inside
| File or folder | Purpose |
|---|---|
| `00-MASTER-PROMPT.md` | The prompt to paste |
| `01-experience-and-art-direction.md` | The noble look, the "Crossing at First Light" scroll story, motion and craft details |
| `02-psychology-and-conversion-map.md` | Persuasion principles with where they are used and their ethical limits |
| `03-benchmarks.md` | Award-winning and luxury sites studied, and the usability research we follow |
| `04-acceptance-checklist.md` | Definition of done |
| `docs/` | Full build brief (Markdown and PDF) |
| `messages/en.json`, `messages/ar.json` | All approved website copy in English and Arabic, ready for next-intl |
| `starters/` | Design tokens, Zod form schemas, content models, site config, database schema, `.env.example` |
| `assets/posters/` | The five campaign posters |
| `assets/reference/` | Strategic blueprint and the Claude Design master prompt |

Contact email, WhatsApp number, WhatsApp community link, domain, social links, membership cost wording, response time, founder note, the final logo from Claude Design, and privacy wording checked by an adviser.
